# DERIVA

Mapa-first de micro-paseos vecinales. Solicitud ≠ plaza.

```bash
cp .env.example .env   # DATABASE_URL + JWT_SECRET
pnpm install
pnpm api               # :3014
pnpm start             # :4200
```

Guía demo: `iago@deriva.barrio` / `password123` (crear con `POST /api/auth/register` en el primer arranque).
